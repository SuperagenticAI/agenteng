# Participate in Agent Engineering HQ

You can suggest a talk, an event topic, a workshop or a way to improve this project. Suggestions help organizers understand community interests; they do not create a commitment to run an event or accept a speaker.

## Speaker proposals and private enquiries

Send a proposal to [events@agentengineering.world](mailto:events@agentengineering.world). A useful first message has a working title, short abstract, intended audience, practical learning outcomes, preferred city/format and a relevant public link. Share only the contact information needed for a reply. Do not send attendee lists, identification documents, proprietary material or confidential employer information.

This channel is available for London/San Francisco ideas and enquiries; it is not a promise of an active call for proposals. London 2026 has an invited programme and no public CFP. Organizer review, program fit and available time determine what happens next. Sending a proposal does not guarantee acknowledgment, review by a particular date, acceptance, compensation, travel arrangements, scheduling or publication. An explicit organizer agreement is required for those commitments.

## Public event discussions

For an idea you want to discuss openly, use the repository's **Public event idea** issue form. GitHub issues in a public repository are public, including their edit history. Use public project links or your GitHub handle; keep email addresses, private proposals and contact details out of the issue.

Describe the problem practitioners face, the audience, a possible topic/format and why it would be useful. Community comments and interest are signals, not bookings or binding votes. Maintainers may merge duplicates, defer or close ideas. Organizers decide separately whether an idea becomes an event.

## Software feedback

Use the bug or feature issue form for CLI, catalogue, MCP/A2A and documentation feedback. Private security reports follow [SECURITY.md](../SECURITY.md). Code contributions follow [CONTRIBUTING.md](../CONTRIBUTING.md).

## CLI and agent participation

The CLI and agent help you discover London/San Francisco events and prepare local drafts. Run `agenteng participate`, ask “How can I propose a talk?”, or use `{"operation":"participate"}` through MCP/A2A for organizer contact and a proposal checklist. `agenteng engage` guides a future-event idea; draft/preview/export sends nothing.

An optional private intake pilot is disabled by default. When the organizer configures it and issues participant access, explicit preview/confirmation can store a proposal in the one private Agent Engineering HQ inbox. A durable receipt confirms storage; “received” is distinct from “accepted.” Proposals remain outside the public catalogue. Acceptance does not schedule or publish a talk; that requires separate organizer agreement and contributor consent. See [participation usage](PARTICIPATION.md) and [coding-agent integrations](INTEGRATIONS.md).
