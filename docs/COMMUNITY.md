# Community contributions

Contribute public, source-backed corrections to event facts, tool listings, code and documentation. Include the affected record and its public source; avoid attendee details, credentials and private enquiries in issues or pull requests.

AgentEng serves public information only. Event registration and organizer enquiries use the official external channels linked from the catalogue. The tool accepts no proposals or attendee records and cannot schedule a talk. Read [public participation policy](PARTICIPATION.md) for published call status.
